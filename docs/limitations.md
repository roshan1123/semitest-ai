# SemiTest AI MVP Limitations

- All measurements are synthetic software-generated values.
- Acceptance profiles are illustrative and must not be treated as industry-standard semiconductor limits.
- Test evaluation is a demonstration rule engine, not certified quality-inspection software.
- Image inspection is an experimental OpenCV demonstration, not validated defect detection.
- Authentication is intentionally not enterprise-grade in this MVP.
- SQLite is for development; PostgreSQL is a future production option.
- Physical semiconductor test instruments are explicitly unsupported and disabled.
